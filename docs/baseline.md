# Manual baseline (Milestone 2)

Time to complete one quality application **fully by hand**, measured over 1 real application. Recorded 16 Nov 2026.
This is the "before" number the automated system is compared against (PRD §3).

> **Small sample:** based on 1 application (the plan was 5). Treat it as an indicative baseline, not an average.

| | Minutes |
|---|---|
| Total for the application | **120** |

## Where the time goes

| Step | Minutes | Share of time |
|---|---|---|
| Find the role and check it is truly remote | 3.3 | 3% |
| Read the job description and judge fit | 13.7 | 11% |
| Research the company and the poster | 21.8 | 18% |
| Tailor the CV | 21.6 | 18% |
| Write the cover letter | 30.0 | 25% |
| Draft connection note and follow-up message | 15.0 | 12% |
| Apply on the site and send the connection request | 10.0 | 8% |
| Log it in HubSpot | 5.0 | 4% |

At this pace, 5 applications a day would take about **10.0 hours**.

_Aggregates only. The raw sheet (with company names) is kept private._
